x-unrepost

Clean up your X account by topic. You describe what to remove (politics, sports, anything) or what to keep (only tech). An LLM labels each post, you read a dry run, then the tool un-reposts or deletes the matches. It runs on your own machine.

View on GitHub Privacy

What it does

  1. Scan. Reads your recent reposts, replies, quotes and posts into a local CSV.
  2. Classify. An LLM labels each row remove, borderline or keep against rules in a small config file.
  3. Dry run. Shows exactly what would be deleted, with counts and an ETA. Nothing is sent to X.
  4. Delete. Un-reposts by default. Deleting your own replies, quotes and posts is permanent and requires you to type DELETE.

Every command saves progress after each item, so you can stop and resume. It respects X rate limits and waits them out on its own.

Example rules

{
  "mode": "remove",
  "topics": ["politics"],
  "instructions": "NOT political: stocks, finance, AI and tech industry debates."
}

Or flip it: "mode": "keep_only" with topics like software engineering and coding agents, and everything else becomes a candidate for removal.

Get started

Requires Node 22 or newer, an X developer app with pay-per-use credits, and an OpenAI or xAI API key.

git clone https://github.com/cykj40/x-unrepost.git
cd x-unrepost
npm install
npm run init

init offers guided setup (it checks your keys as you enter them) or manual setup. Then:

npm run auth
npm run scan
npm run classify
npm run delete -- --include-borderline --dry-run

Limits and costs

  • The X API exposes only your most recent ~3,200 posts. Older ones can't be scanned or deleted yet.
  • Un-reposts are limited to 50 per 15 minutes. About 1,400 reposts takes roughly 7 hours.
  • Measured on one account: scanning about $3 per 3,200 posts, classifying about $1, un-reposts about 0.7 cents each. These are not guarantees; check current prices.
  • The LLM makes mistakes. Read the dry run before every real delete.
Permanent deletes. Un-reposting is reversible (you can repost again). Deleting replies, quotes and posts cannot be undone. This is an independent project, not affiliated with or endorsed by X Corp. Use it at your own risk.

Privacy

x-unrepost has no server and no accounts. The author does not collect, receive or store your data, and this page has no analytics or cookies. Here is exactly where your data goes when you run the tool:

DataWhere it goes
Your posts, read from XFrom X to your machine, using your own X app and login. Stored in a local CSV.
Post text used for labelingSent to the AI provider you configure (OpenAI or xAI) so it can label each post. For each post that is the id, type, author username, the text, and, for replies and quotes, the text of the post being replied to or quoted. That provider's own terms and privacy policy apply, so check them before you run classify.
Delete and un-repost requestsSent to X, using your credentials.
Your API keys and login tokensStored on your machine only (.env and .x_tokens.json, mode 0600), sent only to X and to your AI provider as needed to authenticate, and never logged.

What's stored locally: data/posts.csv (post text, labels and status), data/scan_state.json, your keys and tokens, and your scrub.config.json, in the project folder or in ~/.x-unrepost. Delete those files to remove everything. To cut off access, revoke the app under X Settings, Security and account access, Connected apps, and delete your API keys with your AI provider.

Never commit or share .env, .x_tokens.json, scrub.config.json or data/.
